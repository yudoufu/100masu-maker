# まいにち100ます — 計算プリントメーカー

たし算・ひき算・かけ算の計算プリントをブラウザ内で作る静的Webアプリです。問題生成にサーバーや外部APIを使わず、入力内容も保存・送信しません。

## Cloudflareでの公開

Cloudflare Pagesの **Direct Upload** で `works/100masu` フォルダをアップロードすれば公開できます。Git連携を使う場合は、ビルドコマンドを空欄、出力ディレクトリを `works/100masu` にします。

HTML・CSS・JavaScriptだけで動作し、Workers Functions、データベース、画像ストレージは使いません。Cloudflare Pagesの無料枠や制限は[公式の制限一覧](https://developers.cloudflare.com/pages/platform/limits/)を参照してください。

## 機能

- たし算、ひき算、かけ算
- 0から9、10、12、20までの数字範囲
- 5×5、10×10、15×15、20×20の表
- ランダム、小さい順、大きい順の出題
- 1、3、5、10、20、30、50枚の一括作成
- 「答えもつくる」をオンにすると、問題プリントの後に対応する答えを印刷
- A4横向きの印刷レイアウト
