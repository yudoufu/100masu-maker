# まいにち100ます — 計算プリントメーカー

たし算・ひき算・かけ算の計算プリントを作成し、印刷できる静的Webアプリです。問題はブラウザ内で生成され、入力内容は保存・送信されません。

## 使い方

`docs/index.html`をブラウザで開き、計算の種類や数字の範囲、表の大きさなどを選びます。「新しい問題をつくる」でプリントを作成し、「問題を印刷」または「答えを印刷」から必要なページを印刷できます。答えプリントは「答えを印刷」を押したときに作成されます。

問題と答えのNo.は対応しています。

## 設定

- 計算の種類：たし算、ひき算、かけ算
- 数字の範囲：0から9、10、12、20まで
- 表の大きさ：5×5、10×10、15×15、20×20ます
- 出題の並び：ランダム、小さい順、大きい順
- 作る枚数：1、3、5、10、20、30、50、100枚
- 問題と答えは、それぞれのボタンから個別に印刷

ひき算では、上の見出し数字に10を加えて、答えが負の数にならない問題を作ります。印刷はA4横向きに最適化しています。
